# Export scope

The release was assembled in a new directory using an allowlist of reusable
skills, helper scripts, style-library text sources, and template text sources.
It began with new Git history. No private project history was imported.

Excluded: source and finished media, personal video projects, reference project
transcripts and EDLs, `.env`, private application state, old imports and archives,
binary caches, third-party reference screenshots, and machine-specific paths.
Synthetic examples were authored separately. Source templates and workflows were
adapted for portable paths and neutral example content.
